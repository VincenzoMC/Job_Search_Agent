Job Search Agent

A personal Python portfolio project by VincenzoMC.

Find and organize job opportunities

Job Search Agent collects postings from public job APIs, filters them against user preferences, compares them with a locally supplied resume, and ranks matches with an understandable scoring system. A local dashboard tracks application status and preserves job history.

Weekly email reports

The desktop application can send a weekly report through a Google account that the user connects. Google authorization requests only the Gmail send scope. The application does not request permission to read the inbox, manage contacts, or delete messages.

Users review every opportunity and apply directly through the employer's posting. This application never submits job applications automatically.

About this website

This is an information site. It does not run the job search, collect resumes, or offer Google sign-in. The job-search program and its stored data run on the user's computer.
