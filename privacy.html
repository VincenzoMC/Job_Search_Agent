Privacy Policy

Effective September 13, 2026. This policy describes the personal Job Search Agent project maintained by VincenzoMC.

Information used by the application

The locally installed application uses job preferences, a user-selected resume, job postings, application statuses and notes, and the configured report recipient. These are stored in local configuration files, reports, and a SQLite database.

Google account access

Google sign-in requests https://www.googleapis.com/auth/gmail.send to send job reports from the account the user authorizes. It does not request inbox-reading, contact-management, or message-deletion access. The program stores OAuth credentials and refresh tokens locally in private files excluded from source control.

Transfers and purpose

Sending a report transmits its contents and recipient address to Google Gmail for delivery. Reports can include job links, match explanations, and skills or gaps derived from the resume. Public job providers receive API requests and ordinary connection information. The default matching process runs locally. Optional AI commentary is disabled by default; if enabled, the configured model endpoint receives the profile and selected job descriptions. Resume-backed matches are excluded from that optional commentary.

Google user data is used only to provide the requested email feature. It is not sold, used for advertising, or used to train generalized AI models. Job Search Agent's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including its Limited Use requirements.

Retention and deletion

Local data remains until the user deletes it. To disconnect Gmail, revoke access in Google Account connections and remove the local Gmail token. Delete local resumes, tracker databases, and generated reports to remove those copies. Backups and emails already delivered must be removed separately from their storage locations or mailboxes.

Website hosting

These static pages use no application analytics, advertising, cookies, or data-entry forms. GitHub Pages may process visitor IP addresses and connection information under the GitHub Privacy Statement.

Contact

For privacy questions, visit the maintainer's GitHub profile. Do not post credentials, resumes, or other private data in public GitHub discussions.
